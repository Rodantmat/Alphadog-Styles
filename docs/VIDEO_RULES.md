# AlphaDog Styles - standing video rules (owner Rodo; permanent, re-read before building ANY video)
1. Post A = morning reel, one new video per day, ONE day scheduled at a time (2 posts/app/day on TikTok, Instagram, Facebook, Pinterest). Post B = Printify-mockup posts at 8pm PT.
2. Weekly rotation (7-day window): Day 4 = MONDAY = 4-dog laugh video (APPROVED concept, social/laugh/build.py). Day 7 = THURSDAY = 2-dog laugh video (APPROVED, social/laugh/build2.py, chihuahua+yorkie clips in out/footage3). Other days rotate the existing video models; the model used last goes to the end of the line.
3. Every re-creation changes: merchandise, merch colour, design, placement/view (back print, big front face, small chest emblem, full dog, head only), background, music. Funny videos: same dogs + same snap-to-laugh effect, NEW dog-related joke each week, new background + music + laugh track. Breed joke -> that breed's merch; otherwise assorted merch.
4. Backgrounds (texture AND colour) and music may repeat only after 2 months. Backgrounds must be structurally different (not a recolour). Never repeat a video style back-to-back. Log everything in docs/style_registry.json + docs/music_log.md.
5. Layout: phone-safe (nothing under app UI), joke fixed on top the whole time, dog tiles centred with wiggle space, answer under; text never covers merchandise (top text high, bottom text low); merch big; finale = 4 corners + middle, ~2 s hold; ideal length 8-10 s unless script needs more (laugh videos ~16 s approved).
6. Merch cutouts: only from the trimmed library out/merch_lib (front <code>.webp, back view <code>_back.webp), tested on black: no white, no cut-off garment pieces. Review the finale frame before publishing.
7. Never repeat music across posts. Verify every scheduled post actually went live; repost misses immediately. Videos seen and not corrected are approved. No real orders, no password entry, stay inside Cloudflare $5 / GitHub $4 plans, keep reports short.
