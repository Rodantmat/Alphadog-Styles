Formato de arquivo apropriado
O que é PNG?
A sigla PNG significa “Portable Network Graphics”, sendo um formato de imagem digital utilizado para gerar praticidade, rapidez e qualidade. Este formato foi desenvolvido para superar as limitações de outros formatos, como o GIF, em aspectos como cores e licenciamento. Um de seus maiores atributos é o fundo transparente com uma boa taxa de compressão. 
Formato de arquivo inapropriado
Esses formatos são ótimos para seus determinados segmentos, porém para o silk hd eles não são indicados.
JPEG
: Não indicamos esse formato, pois ele tem como principal característica aplicar fundo na imagem
PDF
: Por ser um formato ideal para trabalhar com vetores e texto em curvas não o indicamos.
SVG
: É um tipo arquivo que se aplicar para páginas da web e afins.
TIFF
: Esse talvez seja o arquivo que chegue mais próximo do recomendado, porém é mais complexo e contém mais atributos gerando um grande número de MB ou até GB tornando-se assim um arquivo, grande, pesado e mais lento para se processar.
