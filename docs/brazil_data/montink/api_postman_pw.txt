POST
Criar Pedido
https://api.montink.com/create_order

Endpoint responsável por gerar um pedido em sua plataforma. Seu pedido aparecerá diretamente em sua dashboard, na página de Pedidos Externos. Após importar o pedido, é necessário efetuar o pagamento utilizando o saldo de sua conta para pagar os custos do pedido, e enviá-lo a produção.

View More
Parâmetro	Descrição	Descrição Adicional
customer_name (Obrigatório)	Nome Completo do Cliente Comprador	String
customer_email (Obrigatório)	E-mail do Cliente Comprador	String - O e-mail será validado em nosso sistema, e caso seja inválido, não será importado.
customer_document (Obrigatório)	Documento do Cliente Comprador	String - CPF ou CNPJ
customer_name (Obrigatório)	Telefone do Cliente Comprador	String - Enviar de Preferência no Formato (DD) 90000-0000
payment_method (Opcional)	Forma de Pagamento do Pedido	String - Todos os pedidos serão importados para pagamento via saldo. Outras formas de pagamentos disponíveis em breve.
value_total (Obrigatório)	Valor Total do Pedido	Double - Valor demonstrativo do valor do pedido. Esse não será o valor final de compra pago via saldo, o valor será calculado pelo nosso sistema.
external_order_id (Opcional)	ID do Pedido em Sua Plataforma	String - Utilizado para identificação de seu pedido em nossa plataforma
shipping_id (Opcional)	ID da Transportadora de Envio	Integer - Para obter o ID da Transportadora, utilize o endpoint calculate_shipping. Caso o ID da Transportadora não seja enviado, selecionaremos a opção com menor preço.
address[zipcode] (Obrigatório)	CEP do Endereço Entrega	O Cep informado será validado pelo nosso sistema. Não será possível importar pedidos com Ceps incorretos.
address[street] (Obrigatório)	Logradouro do Endereço de Entrega	String
address[number] (Obrigatório)	Número do Endereço de Entrega	String
address[neighborhood] (Obrigatório)	Bairro do Endereço de Entrega	String
address[city] (Obrigatório)	Cidade do Endereço de Entrega	String
address[state] (Obrigatório)	UF do Endereço de Entrega	String - Apenas dois Dígitos. Ex: MG, SP, RJ, BA
address[complement] (Opcional)	Complemento do Endereço	String
products[] (Obrigatório)	Produtos do Pedido	Array - Combinação dos produtos com os dados obtidos pelo endpoint products ou product
products[product_id] (Obrigatório)	ID do Produto criado na Montink	Integer
products[sku] (Opcional)	SKU das Variações do Produto	String - Opcional caso não seja enviado os campos var1, var2 e var3 (var3 é opcional)
products[quantity](Obrigatório)	Quantidade de Produtos	Integer
products[var1](Opcional em alguns casos)	Variante 1, normalmente relacionada a tamanho	String - Caso o produto esteja nas categorias de Canecas, Bonés, Garrafas ou Copos, esse campo se torna opcional. Também é aceito o valor ÚNICO
products[var2] (Obrigatório)	Variante 2, normalmente relacionada a cor	String
products[var3] (Opcional)	Variante 3, normalmente relacionada a escolha do Papel	String - Caso o produto seja na categoria Posters, o campo é obrigatório
products[price] (Obrigatório)	Preço demonstrativo do Produto	Double
