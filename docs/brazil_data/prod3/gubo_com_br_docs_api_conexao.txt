A conexão liga a sua loja à API. Cada loja tem uma, com configurações separadas para teste e produção.

GET
/conexao
#

Funciona com qualquer escopo. Use para verificar a chave e para mostrar limites no seu sistema.

curl https://kx75xapy8azwdvdnd4brts7y098e5qvg.buildprintusercontent.com/gubo-api/latest/live/v1/conexao -H "Authorization: Bearer $GUBO_API_KEY"

Campo	Descrição
modo	teste ou producao, conforme a chave
situacao	ativa ou pausada. Pausada: a criação de pedidos está suspensa no Gubo Dev
pagamento	automatico ou aguardar. Veja Pagar
chave	A chave usada na chamada: nome, prefixo, escopos e expiração
limites	Limites diários da conexão. Os campos *_por_minuto valem por chave; loja_por_minuto soma todas as chaves do modo; ip_por_minuto vale por IP de origem
consumo_hoje	Consumo desde a meia-noite de São Paulo
