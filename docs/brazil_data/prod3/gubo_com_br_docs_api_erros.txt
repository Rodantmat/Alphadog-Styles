Erros
Todos os códigos de erro, o que fazer e se vale repetir.
Copiar em Markdown

Todo erro tem o mesmo envelope. Decida pelo erro.codigo, nunca pela mensagem.

{
  "erro": {
    "codigo": "saldo_insuficiente",
    "mensagem": "Saldo insuficiente para pagar este pedido. Faltam R$ 42,30.",
    "campo": null,
    "detalhes": { "saldo_disponivel_centavos": 100000, "total_centavos": 104230, "falta_centavos": 4230 },
    "documentacao": "https://gubo.com.br/docs-api/erros#saldo_insuficiente"
  },
  "request_id": "req_01JA2Y0C4F8G…"
}
codigo é estável. A mensagem é para pessoas e pode mudar.
detalhes é uma lista (erros de campo e de item) ou um objeto (dados do erro).
documentacao leva direto à linha do código nesta página.

Repetir? diz se vale repetir a mesma chamada, com a mesma Idempotency-Key.

Validação
#

422 com erro.codigo igual a validacao (campos) ou itens_invalidos (itens). Cada problema vem em erro.detalhes[], com campo, codigo e mensagem. Todos os problemas vêm de uma vez. Corrija e envie com nova Idempotency-Key.

Código em detalhes[]	Significa
campo_obrigatorio	Faltou o campo
campo_desconhecido	O campo não existe no contrato, como um erro de digitação
tipo_invalido	Tipo errado, como texto no lugar de número
formato_invalido	Formato ou tamanho fora da regra
documento_invalido	CPF ou CNPJ com dígito verificador inválido
cep_invalido	CEP sem 8 dígitos
uf_invalida	UF inexistente
data_invalida	prometida_ate no passado ou depois de 120 dias
sku_desconhecido	O SKU não existe na marca. Pode trazer sugestoes
produto_desconhecido	O produto não existe. Pode trazer sugestoes
cor_desconhecida	A cor não existe
cor_nao_liberada	A cor não está liberada para o produto. Traz cores_liberadas
tamanho_indisponivel	O tamanho não existe para o modelo. Traz tamanhos
variante_indisponivel	A variante está indisponível. Traz motivo
item_duplicado	O mesmo SKU aparece duas vezes. Some as quantidades
quantidade_invalida	Fora de 1 a 100
limite_itens_pedido	Mais itens que o limite da conexão
conflito	Campos que não andam juntos, como entrega.servico com entrega.preferencia

Motivos no pedido
#

Não são status HTTP: chegam no objeto Pedido e nos webhooks.

Onde	Código	Significa

pendencias[]	servico_indisponivel	O serviço de entrega.servico não atende o CEP
pendencias[]	endereco_invalido	A transportadora recusou o endereço
pendencias[]	envio_indisponivel	Não foi possível gerar o envio
motivo_recusa	item_indisponivel	Um item ficou indisponível depois da criação
