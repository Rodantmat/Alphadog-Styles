Dimona API V2

API Dimona Digital.
The easiest way to print and ship T-Shirts and Accessories. Shipping globally and printing locally in Brazil and in the US. 20000 sqf in Rio de Janeiro, Brazil and 7500 sqf in Dania Beach, Florida, and 10000 sqf in Elk Grove Village, IL.
Api Base Domain: https://admin.camisadimona.com.br
API KEY: create an account in camisadimona.com.br

Requests
Order
POST
Create Order
{{api-domain}}/api/v2/order

Items:
Array of SKUs. You should use the field "name", but it's not mandatory.
Delivery:
shipping_speed: PAC or SEDEX delivery_method_id: optional. If you integrated with the Quote Endpoint, you can pass the delivery_method_id here. The shipping_speed field will be ignored
