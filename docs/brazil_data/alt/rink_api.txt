Preciso saber programar para usar a API?

Não necessariamente. Ferramentas como n8n e Zapier recebem os webhooks e chamam a API sem código. A INK ainda não tem conector pronto nelas, então a configuração é feita com os blocos de webhook e requisição HTTP. Se preferir, cole a documentação em texto puro no Claude ou no ChatGPT e peça o fluxo.

Não sou Expert INK. Posso integrar a loja de um cliente?

Pode. A documentação é pública. O lojista gera uma credencial com os escopos que o projeto precisa e passa o token para você, junto com o link da documentação.

Em qual plano a API está disponível?

No plano INKrível. Se a loja mudar para um plano sem o recurso, as credenciais são revogadas automaticamente.

O token expira?

Não. Ele vale até ser revogado no painel. O token completo aparece uma única vez, logo depois de gerado: se perder, gere uma nova credencial e revogue a antiga. Os escopos também são fixos, então para mudar permissões basta gerar outra credencial.

Existe limite de requisições?

Sim, 100 requisições por minuto por loja, somando todas as credenciais. Acima disso a API responde 429 e a chamada deve ser repetida depois.

Por onde é melhor começar?

Pelo dashboard de vendas. Ele usa uma credencial só de leitura, então não há risco de alterar nada na loja enquanto você conhece a estrutura dos dados.
