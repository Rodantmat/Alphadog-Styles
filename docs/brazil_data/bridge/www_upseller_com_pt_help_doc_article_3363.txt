Mercado Livre - Guia para atualizar o status do pacote de pedidos ME1
Atualize no 19 Aug,2026
Copiar Link
I. Descrição da funcionalidade

Quando a entrega de um pedido ME1 falha, é possível atualizar o status do pacote e registrar o motivo da falha diretamente no UpSeller. Após a atualização, o comprador poderá visualizar as informações detalhadas da entrega na plataforma.

II. Condições de aplicação

Método de envio: apenas pedidos com logística ME1

Status do pedido: Enviado

Código de rastreio: o pedido deve ter um código de rastreio válido

III. Acesso para atualizar o status do pacote

Acesse [Pedidos] >> [Processamento de Pedidos] >> [Enviado] >> localize o pedido com logística ME1 >> clique em [Mais] à direita >> [Atualizar Status do Pacote].


IV. Como atualizar o status do pacote?

Clique em "Atualizar Status do Pacote", preencha a URL de Rastreio e as observações do vendedor.


① Histórico de Atualizações: clique em "Visualizar" para expandir o histórico de atualizações. Caso não haja registros, a lista será exibida como vazia.
② Status de Pacote ME1: marque o status de entrega correspondente.
③ URL de Rastreio: insira a URL para rastrear o progresso da entrega do pacote.
④ Observação do Vendedor: o conteúdo das observações será enviado para a plataforma Mercado Livre.
⑤ Após preencher todas as informações, clique em "Atualizar".

V. Perguntas Frequentes

Q1: Não consigo ver o botão [Atualizar Status do Pacote]?
R1: O botão é exibido apenas para pedidos ME1 no status "Enviado". Verifique se o pedido atende a essa condição.

Q2: É possível alterar após a atualização?
R2: Depende do status do pacote selecionado anteriormente:

"Enviado" (e todos os seus substatus): é possível modificar novamente. Enquanto o pedido não estiver marcado com um status final, você ainda pode atualizar para outro status de entrega.
"Entregue" / "Não Entregue": não é possível modificar. Esses são status finais. Uma vez atualizados com sucesso, o pedido será bloqueado e não poderá mais ser alterado.




Q3: O que acontece ao selecionar "Não Entregue - Devolvido ao Vendedor"?
R3: Ao selecionar essa opção, o pedido será marcado pela plataforma como "Não entregue" e o processo de reembolso será iniciado.

Q4: O comprador consegue ver as observações do vendedor?
R4: Sim. As observações do vendedor são sincronizadas com o Mercado Livre e ficam visíveis para o comprador.
